이 페이지가 실제 앱과 다른 점

여기서는 SVG를 <img> 로 불러옵니다. 그래서 app/globals.css 의 CSS 변수가 SVG 안으로 상속되지 않고, 각 SVG에 적어둔 폴백 색이 보입니다. 거꾸로 말하면 이 화면이 제대로 보인다는 것은 폴백이 전부 살아 있다는 뜻입니다.

같은 이유로 currentColor 로 그린 것들(아이콘, 배지 프레임)은 물려받을 부모가 없어 브라우저 기본 글자색으로 나옵니다. 앱에서 보게 될 색이 아닙니다.

앱에서는 SVG를 인라인으로 넣기 때문에 토큰과 color 가 그대로 적용되고, --color-eye 같은 값을 런타임에 바꾸면 즉시 반영됩니다.
